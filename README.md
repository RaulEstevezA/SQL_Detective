# SQL Detective

<p align="center">
  <img src="./public/sql-detective-logo.png" alt="SQL Detective logo" width="160">
</p>

An interactive crime novel you solve in real SQL. Puerto Ceniza, 1987: somebody is deleting the police archive from inside, and the analyst who inherits the desk of the woman who found out has to prove it, one query at a time.

**Play:** [raulesteveza.github.io/games/SQL_Detective](https://raulesteveza.github.io/games/SQL_Detective/)

- 🇬🇧 **English:** [Full documentation](./README_en.md)
- 🇪🇸 **Español:** [Documentación completa](./README_es.md)

## What is this repository?

The source of the game: 24 bilingual cases in 5 chapters, with SQL running in the browser through SQLite and WebAssembly. There is no backend and no account; progress stays in the browser.
