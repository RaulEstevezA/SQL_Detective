# SQL Detective

Learn SQL by solving database mysteries through interactive queries and progressively challenging cases. The game runs entirely in the browser with fictional data and read-only queries.

**Live game:** [raulesteveza.github.io/games/SQL_Detective](https://raulesteveza.github.io/games/SQL_Detective/)

- 🇬🇧 **English:** [Full documentation](./README_en.md)
- 🇪🇸 **Español:** [Documentación completa](./README_es.md)

## Development

```bash
npm run dev
npm test
npm run build
```

The production build is written to `dist/`. Run `npm install` once before development or building.
