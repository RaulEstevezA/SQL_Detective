Learn SQL by solving database mysteries through interactive queries and progressively challenging cases.

**Play:** [raulesteveza.github.io/games/SQL_Detective](https://raulesteveza.github.io/games/SQL_Detective/)

- 🇬🇧 [Full description in English](./README_en.md)
- 🇪🇸 [Descripción completa en español](./README_es.md)

## Highlights

- 15 bilingual cases: 3 tutorials, 9 investigations and 3 multi-stage dossiers.
- SQL executed locally with SQLite through `sql.js` and WebAssembly.
- Progressive content from `SELECT` and `WHERE` to joins, CTEs and window functions.
- Detective notebook, final accusations, optional clues and solution explanations.
- Responsive and keyboard-accessible interface.
- Local progress and no backend.
